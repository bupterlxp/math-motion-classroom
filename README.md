# 课堂动势 · Math Motion

一个面向初中数学老师的轻量教学演示工作台。输入教学需求，生成可预览的动画课件，并下载为独立 HTML 文件分享给学生。

## 本地运行

这是一个无构建依赖的静态站点，可以直接用任意静态服务器运行：

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173> 即可体验。

## 当前能力

- 正方体展开图的可播放、可拖拽时间轴演示
- 教学目标、课堂流程、课堂提示和教师备注
- 互动小测与即时反馈
- 生成后下载独立 HTML 演示文件
- 分享链接、学生视角、浏览器本地工作空间与登录模拟

后续可以把 `app.js` 中的 `generatedHtml` 替换为服务端 Codex 生成接口，并把本地登录和历史课件替换为真实账户与数据库。
